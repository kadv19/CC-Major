📋 Demo Script - 3-5 Minutes

  1. Load Demo (10s): Click 🚀 Load Demo Data → 3 medicines appear (Metformin en-US, Dolo kn-IN, Vitamin D3 hi-IN) • Check LED yellow blink, buzzer pulsing
  2. Speaker Test (30s): Click 🔊 Test Speaker on Dolo card → Hear Kannada “ಅಮ್ಮ, Dolo 650 ತೆಗೆದುಕೊಳ್ಳುವ ಸಮయ...” • Adjust volume/speed sliders → replay
  3. Hindi Test (20s): Click `Test Speaker` on Vitamin D3 → Hear Hindi • Then `▶️ Play Reminder` in Speaker section with `hi-IN` selected
  4. Upload Mock OCR (40s): Drag `any.jpg` to upload zone → `Analyze` → see 1-3 medicines extracted → `Add All to Schedule` → new cards appear • Check history
  5. Due Now (20s): Click ⏰ Simulate Due Now → LED fast blink + buzzer fast + beep 880Hz → ✅ Mark as Taken → LED green, buzzer stops, compliance ↑
  6. Buzzer & LED (15s): Click 🔇 Mute → buzzer muted persists, 🔔 Trigger Buzzer → beep+vibration, 💡 Trigger LED → flash
  7. Filters & Timeline (15s): Click `⏳ Pending` → only pending, `✅ Taken` → taken, `24-Hour Timeline` shows dots
  8. Compliance (10s): Show Caregiver Dashboard `33% → 66% → 100%` after marking, `Next dose` updates, browser tab badge `💊 (2)`
  9. Reset (5s): Click 🔄 Reset Demo → clears DB via /api/demo/reset, history, shows empty state
Tech Highlights to Mention: Offline-first (SQLite file + localStorage fallback, no cloud), Web Speech API free (kn-IN/hi-IN/en-US), Web Audio 440Hz, Flask + SQLite, vanilla JS, Chrome best, responsive 48px touch, dark mode, ARIA.
